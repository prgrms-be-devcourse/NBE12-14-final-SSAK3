# 보고서 접수 누락은 서버가 복구하고, AI 생성 재시도는 강연자가 결정한다

강연 종료와 함께 보고서 접수 필요 여부를 기록한다. 서버가 종료 직후 멈추더라도 강연자가 다시 방문할 필요 없이 같은 보고서를 접수할 수 있다. 도입 전에 이미 종료된 강연의 미접수 보고서는 강연자가 생성을 선택할 수 있다.

모델이 생성을 마친 뒤 응답만 유실되면 다음 호출에도 비용이 들 수 있다. 초기 구현은 일시적인 공급자 장애로 분류한 경우에만 소유자가 같은 보고서로 한 차례 더 생성을 요청하도록 했다. 원인 구분을 도입하기 전에 실패한 보고서는 당시 결과를 보존한다.

백그라운드 생성에서는 이미 받은 응답 ID가 있으면 서버가 같은 결과를 다시 조회한다. 응답 ID를 받기 전에 연결이 끊겼다면 강연자는 결과를 기다리거나 남은 한 번의 재시도를 사용할 수 있다. 첫 요청과 재시도가 모두 접수됐을 때는 먼저 검증된 결과를 보관한다. [후속 구현과 검증 결과](../experiments/report-background-recovery.md)
