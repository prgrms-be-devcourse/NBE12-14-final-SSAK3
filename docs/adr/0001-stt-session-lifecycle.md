# 강연방마다 하나의 탭에서 발언을 기록한다

동시에 시작 요청이 들어와도 강연방에는 진행 중인 음성 인식 세션을 하나만 두며, 최초 생성은 `201`, 기존 세션 반환은 `200`으로 응답한다. 응답을 놓친 탭은 같은 세션으로 기록을 이어가고 다른 탭은 이미 기록 중임을 표시해 동일한 발언의 이중 전사를 막는다.

일시 중단 후 자동 복구되면 같은 세션에 누락 구간을 남긴다. 직접 중지하면 `STOPPED`, 복구할 수 없는 오류가 발생하면 `ERROR`로 종료하며, 해당 세션의 첫 종료 상태와 시각은 이후 중복·지연 요청에도 유지한다.

브라우저는 시작 동작마다 식별 키를 생성하고 동일 요청을 재시도할 때 재사용한다. 서버는 강연방 소유권을 확인한 뒤 최초 시작 키와 대조해 기록 가능 여부를 반환한다. 다른 탭을 여는 것만으로 기록을 넘기지 않으며, 강연자가 복구를 선택하면 기존 세션을 종료하고 새 세션을 시작한다. 이후 기존 탭이 종료된 세션에 보내는 새 전사는 거부한다.

같은 시작 키로 지연된 요청이 도착하면 최초 세션의 현재 상태를 반환한다. 그 세션이 이미 종료됐다면 이후 생성된 세션의 상태도 그대로 유지한다.

강연자가 정상적으로 인식 중지 또는 강연 종료를 선택하면 브라우저는 음성 인식을 멈추고 마지막 확정 전사까지 서버의 저장 확인을 받은 뒤 세션을 종료한다. 원래 탭을 사용할 수 없어 다른 탭에서 복구할 때는 기존 세션에 이미 저장된 전사를 보존하고 새 세션을 시작한다.
