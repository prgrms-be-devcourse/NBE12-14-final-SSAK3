# WebSocket은 연결 직후 AUTH 메시지로 인증한다

SCRUM-55에서는 URL 쿼리의 액세스 토큰 대신 연결 직후 `AUTH` 메시지로 토큰을 전달한다. URL 로그에 토큰이 남는 것을 피하는 대신, 인증 전 연결 상태와 10초의 인증 제한 시간을 관리한다. 인증 전에는 경기 메시지를 허용하지 않는다.

JWT 규약과 로그인은 인증 담당 영역이다. WebSocket은 `AccessTokenVerifier`가 검증한 사용자 ID만 사용하고, 실제 검증 구현이 없으면 모든 인증을 거절한다. 테스트의 가짜 검증기를 실제 서비스 인증으로 사용하지 않는다.
