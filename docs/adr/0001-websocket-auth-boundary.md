# WebSocket은 연결 직후 AUTH 메시지로 인증한다

SCRUM-55에서는 URL 쿼리의 액세스 토큰 대신 연결 직후 `AUTH` 메시지로 토큰을 전달한다. URL 로그에 토큰이 남는 것을 피하는 대신, 인증 전 연결 상태와 10초의 인증 제한 시간을 관리한다. 인증 전에는 경기 메시지를 허용하지 않는다.

JWT 규약과 로그인은 인증 담당 영역이다. WebSocket은 `AccessTokenVerifier`가 검증한 사용자 ID만 사용한다. 실제 구현인 `JwtAccessTokenVerifier`를 필수 의존성으로 주입하며, 구현 Bean이 없으면 애플리케이션 시작이 실패한다. 통합 테스트도 같은 검증기를 사용하고 실제 회원가입·로그인으로 발급받은 JWT로 연결한다.
