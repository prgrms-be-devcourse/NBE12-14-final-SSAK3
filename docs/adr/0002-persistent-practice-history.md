# 연습 풀이 이력의 영구 저장

연습이 끝난 뒤에도 풀었던 문제와 선택한 답, 정답 여부 및 해설을 다시 확인할 수 있어야 한다. 결과 요약만 DB에 저장하고 문제별 기록을 Redis에 임시 보관하면 이 요구를 충족할 수 없으므로, 연습 세션에 연결되는 문제별 기록 테이블을 추가해 영구 저장한다. 스키마 변경 비용을 감수하며, 복습 목록에는 사용자가 선택한 문제만 별도로 저장한다.

관리자가 문제를 수정해도 과거 선택과 채점 결과를 일관되게 확인할 수 있도록 풀 당시 문제·보기·정답·해설을 함께 보존한다. 최신 문제만 참조하는 방식보다 저장량이 늘어나는 것을 수용한다.

`practice_answers`와 `practice_choices`에 출제 당시 사본과 제출 결과를 보관한다. `practice_progress`의 학습 회차를 변경하는 방식으로 진도를 초기화하므로 과거 기록은 삭제되지 않는다.
