# SCRUM-156 보고서 샘플 4종 — 입력 데이터와 실제 생성 결과

이 문서는 2026-11-18에 실행한 최초 실험의 저장된 결과를 팀원이 읽기 쉽게 옮긴 것이다. **AI 요약 문장은 수정하지 않았으며**, 소제목·근거 표기·검토 메모만 덧붙였다. Markdown 정리 과정에서 LLM을 다시 호출하지 않았다.

전사 텍스트 파일을 읽어 사용했으며 이번 실험에서 마이크나 Web Speech API로 새 전사를 생성한 것은 아니다. 앞부분의 작성자·날짜와 말미의 서비스 주소를 제외하고 타임스탬프별 발언을 추출했다. 전사 오인식은 임의로 교정하지 않았다.

일반·소수 반응·상반 의견에는 동일한 전체 추출 전사를 넣었다. 기록 누락 사례에서만 **18:00 이상 24:00 미만에 시작하는 발언**을 입력에서 제거했다. 원본 파일 자체는 변경하지 않았다.

표시 시각은 모두 강연 시작 후 경과 시간이다. 내부 JSON의 `2026-11-18T00:00:00Z`는 실험용 기준 시각이며 실제 녹음 날짜가 아니다. 원문에 발언 종료 시각이 없어 `endAt=null`로 두고 발언 시작 시각의 60초 구간에만 연결했다. 다음 발언 시작을 앞 발언의 종료로 추정하지 않았다.

### 청중 데이터 구성

아래 질문과 의견은 **원문 파일에서 추출한 실제 청중 질문이 아니라**, 보고서 동작을 확인하기 위해 구성한 가상 입력이다. 각 시나리오는 독립적으로 실행했고 서로의 채팅을 섞지 않았다. 악성 채팅은 포함하지 않았다.

| 시나리오 | 채팅 | 이해도 체크 | 일반 투표 | 전사 |
| --- | ---: | --- | --- | --- |
| 일반 반응 | 4건 | 1회, 응답 2건 | 1회, 응답 3건 | 전체 |
| 소수 반응 | 1건 | 없음 | 없음 | 전체 |
| 상반된 의견 | 2건 | 없음 | 없음 | 전체 |
| 기록 누락·분석 실패 | 1건 | 없음 | 없음 | 지정 구간 제거 |

LLM에는 전사, 채팅 원문, 서버에서 계산한 마감 투표 집계, 기록별 근거 ID·시간대, 누락·실패 정보를 전달했다. 투표 개인별 응답은 집계에만 사용하고 LLM 입력에는 포함하지 않았다. 기존 청중 AI 분석의 성공 요약은 제공하지 않았으므로 그 재사용 경로를 검증한 실험은 아니다.

## 3. 연결된 강사 발언 원문

실제 생성 요약에서 직접 STT 근거로 참조한 발언은 소수 반응 사례의 다음 두 개다. 아래는 입력 전사 그대로이며 전사 오류를 교정한 문장이 아니다. 다른 사례도 전체 전사를 입력받았지만 최종 요약의 직접 근거로는 채팅·투표를 선택했다.

### STT_SEGMENT:9017 — 18:41

> 이설님의 판단 자체는 굉장히 간단해요. 뭔가를 실행시키려고 하는 사람은 그거에 대한 대가를 지불해야 돼요.
> 그러면 그 대가만큼 실행을 시키는 데 차감이 되는 거예요.
> 어떤 인스트럭션을 실행시킬 때는 얼마만큼의 대가가 까지는 거야 삭제되는 거야.
